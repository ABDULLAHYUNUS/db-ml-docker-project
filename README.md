\# Docker Ortamında PostgreSQL ve Makine Öğrenmesi EntegrasyonuBu proje, Docker konteynerleri üzerinde çalışan bir PostgreSQL veritabanı ile makine öğrenmesi modelinin iki yönlü entegrasyonunu sağlamaktadır. Manuel CSV dosyası kullanılmadan doğrudan veritabanı üzerinden veri çekilmiş, eğitilmiş ve tahmin sonuçları tabloya geri yazılmıştır.\## Kullanılan Teknolojiler\- Python 3.9\- PostgreSQL (Docker Konteyneri)\- Scikit-learn (Logistic Regression)\- Psycopg2-binary\- Docker\## İki Yönlü Veri Akışı1\. \*\*Veri Çekme:\*\* `patients` tablosundaki hasta verileri sorgulanır.2\. \*\*Tahmin:\*\* Lojistik Regresyon modeli risk durumunu tahmin eder (1: Riskli, 0: Sağlıklı).3\. \*\*Güncelleme:\*\* Tahmin değerleri veritabanındaki `prediction` sütununa yazılır.\## Çalıştırma Adımları1\. PostgreSQL konteynerini başlatma:&#x20;  `docker run --name project\_db -e POSTGRES\_PASSWORD=secret123 -p 5432:5432 -d postgres`2\. Uygulama imajını oluşturma:&#x20;  `docker build -t my\_ml\_app .`3\. Modeli çalıştırma ve veritabanını güncelleme:&#x20;  `docker run --rm my\_ml\_app`
